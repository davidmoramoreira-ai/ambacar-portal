# ambacar-portal

#  Portal Web Oficial - Ambacar Ecuador

Plataforma web interactiva desarrollada para el distribuidor de automóviles **Ambacar**, diseñada para ofrecer una experiencia completa a los clientes: catálogo de vehículos en tiempo real, buscador avanzado, sistema de cotización de financiamiento personalizado, ubicación de sucursales a nivel nacional y sección del equipo de desarrollo.

---

##  Tecnologías y Herramientas Utilizadas

* **Frontend:** JavaScript (ES6+), HTML5, CSS3
* **Empaquetador de Módulos:** Vite
* **Control de Versiones:** Git & GitHub
* **Autenticación Local:** LocalStorage API para manejo de sesiones de usuario

---

##  Características Principales

1. **Autenticación de Usuarios:** Sistema de inicio de sesión y registro con validación local para acceder a las funciones interactivas.
2. **Catálogo Dinámico:** Visualización detallada de modelos de vehículos (SUVs, camionetas 4x4, etc.) con especificaciones y precios base.
3. **Buscador en Tiempo Real:** Filtrado instantáneo de vehículos por nombre o categoría.
4. **Cotizador de Financiamiento:** Cálculo automático de cuotas mensuales ingresando el monto de entrada y seleccionando plazos de pago (de 12 a 60 meses).
5. **Mapa y Sucursales:** Información de contacto y direcciones físicas de las principales agencias de Ambacar en Ecuador (Quito, Guayaquil, Cuenca, Ambato).
6. **Sección de Desarrolladores:** Tarjetas de presentación del equipo creador del proyecto.
